Placement Monitoring KitMonthly data checks, measured on planted errors first

For teams that follow placements month by month: four English and French forms (intake, monthly check-in, host feedback, exit) for KoboToolbox or ODK Central; one double-click a month runs 15 data checks, computes 39 indicators and writes the tracker, a 2-⁠page brief and an 8-⁠slide deck.

In one minute

A placement programme follows every intern month by month: whose form is missing, where the data is wrong, what to report this month; done by hand, it is slow and things slip.

I first checked what exists: paid monitoring platforms need money and accounts and have no internship templates; university placement systems do not cover offline collection or French; no public repository had a placement check-in form. So the kit joins recognised wording and indicator definitions: exit and destination questions and the employment classification follow the international labour statistics standards, and the kit’s own questions are marked as such. The monthly run reads the form exports, checks the data, lists who to follow up with reminder text ready, and writes the tracker, a brief and a deck. The checks were measured first on a constructed sample: 50 consenting interns, 18 host organisations and 7 months, with planted errors and records that look wrong but are not.

A data-checking program has to show first that it is accurate: measured on a sample with known answers, it must flag every error and nothing else. With every report number traced to its row, the team can take the brief to a meeting or to managers without checking it by hand.

04/ 05

Limits

01The sample is constructed

the kit has not yet run in a live programme, against a live KoboToolbox or ODK Central server or in ODK Collect, and has run only on Windows. Recommendation: Before going live, set up a test project on the team’s own server and run the monthly cycle once with a few test submissions.

02The French text still needs a read by a French-speaking colleague in the country

some check-in and host-feedback questions have no recognised instrument and use the kit’s own wording, marked as such. Recommendation: Write the changes back into the forms' xlsx and rebuild; after a month or two, revise questions by how they are answered.
