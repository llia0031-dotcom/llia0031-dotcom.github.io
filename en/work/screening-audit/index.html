Evidence-backed resume screeningResume screening where every verdict quotes the resume

Tests whether having the model attach a resume quote to every met / not-met verdict, checked by the evidence-check script, makes screening more accurate and more stable when name, gender, school, career gaps or marital details change.

In one minute

When a model screens resumes, every met / not-met verdict should carry a resume quote; does that make it more accurate, and do verdicts change when name, gender or school change.

I wrote fictional jobs and resumes with answers fixed in advance and compared plain scoring, quotes, and quotes plus the script; after finding that the check discarded correct verdicts I rewired it twice; then tested with trap-laden new resumes, planted errors and an independent second review.

Quotes cost no accuracy and swapping name, gender or school does not change decisions; but the check must be wired in the right place and stops fabrication, not misreading, so a second review is needed.

What I assumed

Expected the script check to cost little accuracy

What the data showed

It cost far more: verdicts restating job thresholds were thrown out

  • 0/240 Decisions changed when only the name changed 0.0%, 95% CI 0.0 to 1.6%
  • 0/424 Correct verdicts wrongly removed (before the fix: 70/424) 0.0%, 95% CI 0.0 to 0.9%
  • 80/80 Misread resumes, all caught by the second review 100.0%, 95% CI 95.4 to 100.0%

Evaluation

Round 1: accuracy and stability (228 resume versions)

228 versions, 2 runs per arm, 1,368 calls; claude-haiku-5-5, standard API

  • Advance decision changed by a name swap (plain) 0/240
  • Advance decision changed by a name swap (with quotes) 0/240
  • Requirements right (quotes + script) 2379/2736
  • Requirements right (with quotes) 2735/2736

Round 2: a better way to wire the check (12 new resumes)

48 versions, 4 arms × 2 runs, 384 conversations; claude-haiku-5-5, standard API

  • Correct “met” lost to the check (quotes + script) 70/424
  • Correct “met” lost to the check (resume facts split out + script) 10/424
  • Correct “met” lost to the check (self-check + script) 0/424

Round 3: messier resumes with traps (24)

24 resumes, 40 traps, 3 arms × 2 runs; claude-haiku-5-5, Message Batches API (half price)

Planted errors: what the script stops

409 base answers; Deterministic script, 1 run; No model calls, no cost

  • Misreadings stopped 0/40

Independent second review

143 items, 2 runs per arm; claude-haiku-5-5, Message Batches API (half price)

  • Misreadings caught (reason visible) 80/80

Limits

01Resumes are fictional and short and come from the same author as the answers

one model, one setting. Recommendation: Before launch, re-test on anonymised real resumes and the team’s own jobs.

02The misreadings were written in, and the review uses the same model as the screening

Recommendation: Use a model from another provider for the review, or review a sample by hand.

03One cell of the answer key is disputed, and it is where round three’s only wrong cell sits

Recommendation: Mark disputed answers and report them separately from the main metric.
