In one minute

Answers and drafts written from documents quietly shift dates and numbers or add facts no document states; every factual sentence should carry a word-for-word quote that a script checks.

I took TraceDesk’s word-for-word quote and number rules out into a skill and checker anyone can install; found problems in a development run, wrote v0.2, and compared it with a plain prompt on frozen Questions kept out of all tuning and used only for the final score. items; then revised the rules twice (0.3.0, 0.4.0) from false alarms in real use and a list of known gaps, writing new items before each change.

The skill’s effect shows mainly in free answers, which no longer invent numbers; the script alone misses contradictions in meaning, so passing claims are reread one by one.

  • 60/60 Errors hidden in drafts on purpose, all flagged 100.0%, 95% CI 94.0 to 100.0%
  • 0/32 Answers with a made-up number (without it: 4/32) 0.0%, 95% CI 0.0 to 10.7%
  • 11/11 Correct claims no longer flagged after the fix (was 0/11) 100.0%, 95% CI 74.1 to 100.0%

Limits

01Items and skill come from the same author, on fictional documents

one model, two runs, one day. Recommendation: When adding it to another agent, test again with that setting’s own documents and errors.

02On its own the script misses contradictions in meaning

a real quote with the right numbers can be cited for the opposite claim. Recommendation: That is why the skill makes the agent reread every passing claim; add an independent second check for more safety.

03Chinese quotes need at least four characters, so complete shorter phrases are blocked

translated group names and ordinals far from the quote are not yet recognised. Recommendation: These are on the list for the next version, which will again get new items before the change.
