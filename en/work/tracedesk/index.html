In one minute

An FAQ assistant that answers only from given documents with word-for-word quotes, putting key facts such as deadlines first with their source.

We built an FAQ assistant for readers who find dense text hard: one sentence first, then a checklist, then the evidence; the server checks every quote and deadline; the prompt went from grounded-v2 to v2.4, with v2.2 to v2.4 each compared with a plain prompt on the same cases.

The grounded prompt beats the plain prompt on the automatic checks at a higher cost; the second run came after seeing the first, so it is not a clean Questions kept out of all tuning and used only for the final score. result.

  • 20/20 Answers passing every check (plain prompt: 17/20) 100.0%, 95% CI 83.9 to 100.0%
  • 20/20 Every deadline sourced (plain prompt: 17/20) 100.0%, 95% CI 83.9 to 100.0%
  • US$0.0134 Cost for the same questions (plain prompt: US$0.0093)

Limits

01Only 40 cases on fictional documents

the second run changed the prompt after seeing the first, so it is not a clean held-out result. Recommendation: For the next version, freeze a new unseen set before comparing.

02The quote check proves the quote exists, not that it supports the answer

automatic checks also raise false alarms, so factual correctness needs a separate item-by-item check. Recommendation: Add a meaning check, as evidence-check does by rereading every passing claim.

03The grounded prompt costs more

US$0.0134 for v2.4 against US$0.0093 for the plain prompt on the same 20 cases. Recommendation: At volume, send shorter document excerpts or cache the unchanging part.
