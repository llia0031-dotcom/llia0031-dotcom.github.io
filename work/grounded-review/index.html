有据审核（广告审核 Agent）广告​审核​说​清​违反​哪​一条、​是​哪​几个​字

审核广告的 Agent：读文案和图片里的字，在 32 条政策条款里查依据，给出放行或拒绝；每处违规附类别、条款、违规原话和条款原文，引文先过 evidence-check 的核对脚本才算数。

一分钟看完

广告审核要说得出违反哪一条、是哪几个字违反的，而不只是给“通过 / 拒绝”。

我从官方原文整理了 32 条政策条款，写了带陷阱的专门留着、不参与调试的一组题，只在最后用来打分。，做了能查条款、引原文、多轮改稿和复审的 Agent，并和单个提示词、违禁词表、开源审核模型比较；改稿建议从 v1 迭代到 v1.3；最后换成监管机构和法院定答案的真实广告。

自己写的题两组都到顶；换成真实广告后，Agent 比单个提示词更严，大部分错来自监管规则和政策库不同。

动手前以为的

以为会漏在小字、小国旗和画出来的喝酒场景上

评测数据说明的

这些一次都没漏；自己写的题到顶，换成真实广告才分出差别

局限

01自己​写的​题​到​顶了

留出集两组都接近满分，难题集两组都全对，分不出 Agent 和单个提示词谁更好。建议：要分高低，用不是自己写的题：更多真实裁决、更长的视频，或模型没见过的规则。

02Agent ​比​单​个​提示词​更​容易​误拒​陷阱

留出集陷阱放行 55/60，单个提示词 59/60；Agent 的费用也更高。建议：合规但像违规的广告（送达保证、文化遗产名录、定价）要给 Agent 补正面例子或条款说明。

03真实​广告​上的​错​大多​来自​规则​不同

英国判不违规的酒类广告，按 TikTok 政策要写酒精度，两组都拒了。建议：上线时政策库要和执行规则的那一方一致；跨市场时按市场分库。

04多​轮​改稿的​题​只有 ​12 ​条​短​文字​广告、​一个​模型

相差一两段对话属于噪声。建议：下一版改稿提示词上线前，用图片广告和更长的文案再测一轮。

05开源​审核​模型​一张​图​要​几​分钟，​不​给​条款​和​原话

SafeGuard-VL-RL 每张图约 178.3 秒。建议：开源模型适合当便宜的第一道筛子，拿不准的再交给带依据的审核。

06记忆​评测的​差别​只​来自​一条​广告，​题目​是​自己​写的​短​文字​广告，​旧​判定​库​也是​一起​写的

建议：上线前在真实的历史判定和更长的广告上再测；记忆保持只读，写入要经过人工确认。
